GoodMe 功能介绍

当前版本以软件内显示为准 · 以下为能力总览

自瞄 绘制 功能 传送 美化 刷房 设置

自瞄

多种模式与预测算法

  • 支持内存修改、后台静默、路飞静默等多种自瞄模式
  • 预测算法含佛系跟踪、混合算法、AI 算法及独家 GM自研 角度域预测
  • 枪灵觉醒（ADAD）：识别左右晃动并分级抑制预测
  • 调参模式与命中记录，方便针对枪械微调手感
  • 网络延迟补偿与多档内部预设

绘制

战局与摸金信息一眼看清

  • 人物绘制：血量、距离、体力、持物、方框、准心辅助等
  • 摸金绘制：棺材、物资、怪物、龙珠/宝物、传送球、门等
  • 爬山绘制：宝箱分级、商店、重生点、撤离点等
  • 提醒：身后敌人、堵车、堵门、人数变化
  • 装备/背包排行面板，支持同队优先或装备优先

功能

视觉增强与操作减负

  • 视觉：广角视野、超级夜视、环境除雾、地图除雾与棺材显示等
  • 战斗辅助：无后座、近战范围、杀戮光环、快速切枪与维修等
  • 解放双手：自动拾取、开门、提交与撤离等自动化套装
  • 腰包智能：自动换枪、换包、智能换弹等
  • 娱乐：天空盒、音效替换、模型尺寸、个性签名长度解锁等

传送

跑图与摸金路线

  • 地图导航路径绘制，支持手动多路线
  • 小抄路线与小抄窗口，按图直奔目标
  • 圈内传送：物资、棺材、高价值点快捷接近
  • 爬山传送：平滑步进至爬山宝箱 / 最近未开箱

美化

角色与道具外观

  • 多角色皮肤预设与部件混搭，稀有度配色区分
  • 卡头：跨皮肤混搭头脸身，支持自定义 ID
  • 道具美化：刺刀、铲子、猎枪、腰包、伞扇等多种类型
  • 美化特效与即时换装刷新

刷房

房间号效率工具

  • 按前缀 / 后缀 / 包含规则自动刷新房号
  • 一键启停与快捷键控制
  • 客户端房号展示改写，方便筛选目标房

设置

体验与场景适配

  • 界面缩放、菜单背景色 / 背景图、字体切换
  • 主播模式：录屏截图无法捕获菜单（切换后需重启 GM）
  • 热键、物品刷新频率、商品过滤、到期时间显示等
  • 菜单记住上一次点击的二级页，减少重复切换
